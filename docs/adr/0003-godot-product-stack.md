# Godot is the product stack; the TS prototype is the reference

The product will be built in Godot. The existing TypeScript/web prototype (branch `prototype/theme-mod-loop`) is demoted to a rules and contract reference: its mechanics, walkthrough replays, and pack contract carry over; its code does not. Chosen over TS/web for engine-native tooling; web export remains available but is not the primary target.
