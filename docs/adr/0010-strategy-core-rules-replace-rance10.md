# Core rules replaced with a strategy-leaning set; Rance-10 rules kept as native code

**Status**: accepted.

The Rance-10-style rules were judged too shallow to be a game: a run lasted 8 turns with 4 enemies, and nothing carried across runs. v1 replaces them with a strategy-leaning rule set: a run of about 15 chapters, one shared realm per run, a per-run card draft, branch-tree quests, and the four turn phases kept as they are. The Rance-10 rules stay in the code, unchanged, as a native implementation for replay coverage and comparison, rather than being rewritten as a pack. Considered and rejected: keeping the M1 skeleton and deepening it, because the owner judged the problem to be the rules themselves.
