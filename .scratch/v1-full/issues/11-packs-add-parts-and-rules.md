# 11: Packs add parts and rules

**What to build:** A pack can add a new part, with its own state, parameters, and hooks. It can also add rules. Everything is validated and trilingual. A sample pack adds one part that appears on the main screen and changes play.

**Blocked by:** 09 (Budgets and sandbox denials), 10 (Parts system with optional Fatigue)

Status: ready-for-agent

- [ ] The sample pack imports and plays, and the new part changes play in a replay
- [ ] The new part's text is required in zh, en, and ja, and a missing language is a reason at import
- [ ] The new part is visible on the main screen
