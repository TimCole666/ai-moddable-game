# 02: Design the strategy turn rules

**What to build:** Write a short design note for the turn-level strategy rules that the built-in pack will carry. For each rule, state the inputs (state the rule reads), the effects (state it changes), and a starting value that can be tuned at playtest. Cover what the player decides in each phase beyond quest choices and card draft, and how the realm responds. If a decision is hard to reverse and was a real trade-off, record it as an ADR.

**Blocked by:** None (can start immediately)

Status: ready-for-human

- [ ] Every strategy rule has inputs, effects, and a starting value
- [ ] Each rule can be written as an expression over readable state (no clock, files, or randomness)
- [ ] Battle rules are not changed by this design (battle stays as in M1)
- [ ] The owner has reviewed and approved the note
